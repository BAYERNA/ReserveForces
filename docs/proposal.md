## 1. 배경 및 필요성

### 1-1. 현행 체계의 한계
예비군 훈련·동원 소집은 「예비군 교육훈련 훈령」에 따라 모바일 전자고지, 우편, 예비군 홈페이지·모바일 앱 등 여러 채널로 이루어지며, 지연입소·조기퇴소 판정과 같은 현장 처리는 여전히 수기·구두 확인에 의존하는 비중이 높다.

- 소집 대상자 현황과 입영 진행률을 부대 담당자가 실시간으로 파악하기 어려움
- 지연입소(입영시간 1시간 이내) · 조기퇴소(거주지 100km 이상) 판정 기준이 있음에도, 현장에서 개별 확인·수기 처리가 반복됨
- 소집부대·훈련장 정보가 예비군 개인에게 흩어져 전달되어 문의 대응 부담이 큼

### 1-2. 개선 방향
소집 현황을 한 화면에서 관제하고, 실제 규정을 룰(rule)로 코드화하여 지연입소·조기퇴소 판정을 자동화하면, 부대 담당자의 행정 소요를 줄이고 예비군 개인의 훈련 소집 경험을 개선할 수 있다. 본 아이디어는 이러한 문제의식에서 출발한다.

## 2. 아이디어 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 예비군 동원소집 통합 관제 시스템 (가칭) |
| 한 줄 요약 | 부대 담당자용 실시간 관제 대시보드와 예비군용 소집 확인 화면을 하나의 웹 서비스로 연동하고, 지연입소·조기퇴소 판정을 규정 기반 룰엔진으로 자동화하는 서비스 |
| 이용 대상 | ① 부대 동원 담당자(관리자 뷰) ② 소집 대상 예비군(개인 뷰) |
| 핵심 가치 | 현황 파악의 실시간성 + 판정 처리의 자동화 + 반응형 웹 하나로 관리자·개인 화면 동시 대응 |

※ 서비스명은 신청서 제출 전 확정 명칭으로 교체 예정

## 3. 핵심 기능

| 기능 | 설명 |
|---|---|
| 실시간 소집 관제 대시보드 | 소집 대상자 현황, 입영 진행률, 지연/조기퇴소 처리 건수를 부대 담당자가 한 화면에서 확인 |
| 소집 확인·안내 화면(예비군용) | 소집통지 확인, 입영 부대·훈련장 정보 조회를 반응형 웹으로 제공(별도 앱 설치 불필요) |
| 규정 기반 자동판정 룰엔진 | 거주지-소집부대 거리, 도착 시각 등 입력값을 기준으로 지연입소(1시간 이내)·조기퇴소(100km 이상) 여부를 규정에 따라 자동 판정 |
| 권한별 화면 분리(RBAC) | 관리자 / 예비군 역할에 따라 접근 가능한 화면과 기능을 구분 |

## 4. 기술 구현 방안

### 4-1. 개발 스택

| 영역 | 기술 스택 |
|---|---|
| 백엔드 | Spring Boot 3.5, DDD/헥사고날 아키텍처, PostgreSQL 16 |
| 프론트엔드 | React 18 + Vite, 반응형 웹(관리자·개인 겸용) |
| 판정 로직 | 규정 기반 룰엔진(자체 구현), 시연용 시나리오 데이터셋 |
| 배포/시연 환경 | 로컬 구동 우선 설계 — 외부 API·인터넷 연결 없이도 시연 가능하도록 구성 |

### 4-2. 시연 안정성 설계
2차 발표심사는 네트워크 연결이 제한되는 환경에서도 시연이 가능해야 한다는 조건이 있다. 이에 따라 실시간 외부 API 호출에 의존하지 않고, 미리 준비한 시나리오 데이터로 관제 대시보드와 판정 로직이 동작하도록 설계한다.

### 4-3. 기존 프로젝트 경험 재사용
관제 대시보드 구조(관리자/현장 인력 역할 분리, 실시간 현황판, React+Spring Boot 조합)는 기존에 직접 설계·구현한 소방 지휘·대응 시스템 프로젝트의 아키텍처를 동원소집 도메인에 맞게 재구성한 것으로, 구현 가능성이 검증된 기반 위에서 개발을 진행한다.

## 5. 기대효과

- 부대 담당자의 소집 현황 파악·판정 업무에 소요되는 행정 처리 시간 단축
- 지연입소·조기퇴소 판정 기준을 규정대로 일관되게 적용하여 처리 오류 가능성 축소
- 예비군 개인의 소집·훈련 정보 접근성 개선으로 문의 대응 부담 완화
- 반응형 웹 기반 설계로 별도 앱 배포 없이 여러 부대·훈련장으로 확장 적용 가능

## 6. 향후 확장 계획

1차 개발 범위는 관제 대시보드와 규정 기반 판정 기능에 집중하되, 이후 아래 모듈을 단계적으로 추가할 수 있도록 구조를 열어둔다.

- 소집·훈련 안내 챗봇 모듈: 지연입소 기준, 훈련 일정 등 반복 문의에 대한 자동 응답
- 현장 신원확인 모듈: 영상 인식 기반 입영 확인으로 대규모 인원 동시 입영 시 처리 지연 완화

두 모듈 모두 관제 대시보드에 부가 기능으로 연결되는 구조로 설계하여, 서비스 확장성·이식성을 확보한다.

## 7. 신청자 소개

KDT(K-Digital Training) 부트캠프 과정에서 백엔드·풀스택 개발을 학습하며, Spring Boot 3.5 기반 모듈형 모놀리스 아키텍처와 React 프론트엔드로 구성된 지휘·관제 시스템을 직접 설계·개발한 경험을 보유하고 있다. 본 아이디어는 해당 프로젝트에서 검증한 실시간 관제 대시보드 구조를 국방동원 도메인에 적용한 것으로, 구현 역량과 도메인 적용 가능성을 함께 갖추고 있다.
